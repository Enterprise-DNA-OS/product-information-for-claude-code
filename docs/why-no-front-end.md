# Why this starts with the records

The five weekly jobs are catalogue checks, content edits, supplier requests, claim reviews and private channel exports. Each works through the database and named commands. npm run view creates read-only HTML snapshots. npm run docs creates product review sheets and supplier briefs. They are internal files, not a deployed application.

Pimberly supplies a browser workspace, media management, collaboration and commerce connections. This base has no interactive grid, drag and drop, mobile capture, offline editing, asset storage or live delivery. A shared team needs authenticated access and suitable database roles. Enterprise DNA scopes those screens and connections around the business as part of a customised version.

The advantage is ownership of the records and checks, including how claim evidence and supplier tasks affect each channel's readiness. The open-source base does not claim feature parity with a full PIM and DAM platform.
